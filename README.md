# WiFi Analyzer — Mod By Vinz :3

Fitur:
- Info WiFi terhubung (SSID, BSSID, RSSI live, band, channel, link speed, standar WiFi, IP, gateway, DNS, DHCP)
- Scan jaringan sekitar (sinyal, channel, lebar channel, keamanan) + saran channel 2.4GHz paling sepi
- Scan perangkat yang terhubung di WiFi yang sama (IP, hostname, MAC kalau bisa dibaca)

Build via GitHub Actions: `gh auth login` lalu `bash push.sh nama-repo`
